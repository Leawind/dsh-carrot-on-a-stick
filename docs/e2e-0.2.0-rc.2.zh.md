## 发现与处置

1. **沙箱 ACL 失败与 cwd 相关（0.1.7 已见，非 0.2.0 回归）**：`agent_run` 以 `D:\Workspace\...`
   实目录为 cwd 时，pwsh 沙箱 `grantWrite` 报 `SetNamedSecurityInfoW failed (Win32 5)`；0.2.0 的
   模型会经 `diagnose-windows-sandbox-acl` 技能尝试**越权诊断修复**，该命令挂审批且无人应答
   （隔离 home 无 GUI），turn 静止。改用 Temp 目录为 cwd 后 pwsh 完全正常、turn 干净完成。
   处置：E2E 的 agent 相固定用 Temp 工作目录；部署侧提示——工作区目录 ACL 异常时，0.2.0 的
   模型可能走技能越权路径触发审批等待，无人值守场景建议配 `taskTimeoutMs` 或调用方自带超时。
2. 本轮无源码/探针改动；`e2e.ts` 两处探针修复（批次 23）在 0.2.0 上继续有效。
